♠ ALLIN · 新手引导 1 / 6

① 500 对 5000：一场不对称的 Boss 战

  • 你 500 筹码，Boss 5000 —— 筹码 = 下注资源 = 生命值 = 战斗进度； 把他的筹码打到 0 就是胜利，你的归零就是失败
  • Effective Stack = min(你, Boss)：每手最多只能从对方身上赢走这么多 —— 你越弱，战场越小；赢回来的筹码会把你的战场撑大（筹码即成长）
  • 盲注会升级：每隔几手盲注翻倍（HUD 上写着当前级别与下次升级）—— 不打就会被盲注磨死，逼你后期正面对决
  • 没有技能栏 —— 所有攻防都通过扑克动作 + READ/CRACK/GOTCHA 完成
筹码即生命：赢 → Effective Stack ↑ → 能打更大的 pot → 赢更多

② 五个按钮，就是全部操作

弃牌 FOLD撤退止损 —— 输小的不算输
CALL / CHECK接招 / 过牌 —— 便宜看牌、静观其变
PRESSURE投入 0.5×当前底池 的中压注（按钮上写着加注到多少）
HEAVY投入 1.0×当前底池 的重压注 —— 让他做决定
ALL IN押上全部 —— 决胜手，筹码即生命

HUD 条带（牌桌上方）从左到右读：牌型（当前成牌）、 Call Cost（跟注要花多少）、Effective Stack（每手最大风险）、 盲注与下次升级、模式（NORMAL / EXECUTION / COUNTER）、 Boss 的三状态情绪（冷静😏 / 动摇😳 / 上头😡）与一行打法提示。

下方两条筹码堆是战况总览：他的在缩、你的在涨，就是你在把他身上夺过来。

③ READ：偷看一眼他脑子里的碎片

  • 按下 READ，Boss 头旁会闪现一行碎片，0.5–1.5 秒后淡出 （他越冷静闪得越久、越上头闪得越快）；同时进入右侧 READ Fragments 面板
  • 本手无限次，只有极短冷却（按钮转圈就是冷却）—— 可以连续发动、按到爽
  • 碎片有三种来源，但绝不标类型：他的真心话、 真实但无关的杂念、以及他自己的错觉与过度自信 —— 三者长得一模一样，全是同一行字
  • 所以必须交叉验证：对照牌面、他的注码、他的行动 —— 「他说别跟」到底是怕你跟，还是想让你弃？只有牌局实况能告诉你

④ CRACK：把真话串成证据链

  • 碎片里带着语义标签（你看不到标签本身，只能从字面判断）； 当多条真话的标签凑成一条规则 —— 屏幕白闪、震屏、「CRACK!」大字
  • 例：「想让你弃」+「牌弱」 连成 WEAKNESS（弱点链）； 「牌强」+「设套」 连成 STRENGTH（强牌链）
  • 出现 CRACK 才解锁 GOTCHA! 按钮 —— 没有证据链，就没有资格押注判断
  • CRITICAL：单条高强度真话直接成链，低概率、高刺激； 证据链只在本手有效 —— 他下一次重要行动会作废旧证据
  • CRACK Feedback 面板列出每条链的 kind、证据标签与强度点数

⑤ GOTCHA：押注你的判断

BLUFF你赌他在虚张声势 —— 他想让你弃牌 / 自己没底
STRONG你赌他真有货 —— 强牌、陷阱，或者在设套等你
  • 按钮弹出二选一确认条，选边落定即提交 —— 服务端拿你的猜测与他的真实意图比对
  • 猜对 → EXECUTION：高压处决阶段 —— 自由下注滑杆开放（任意尺寸 bet/raise）， READ 高速连发、更短更快，还有概率一次闪两条
  • 猜错 → COUNTER：他立刻反扑 —— 本手内注更大、更凶、更敢诈
  • 越富越怕错：Effective Stack 越大，一次判断失误送出的筹码越多 —— 别在没证据时乱按

⑥ 三阶段节奏与快捷键

Early盲注小、观察期 —— 多 READ 攒碎片，小 pot 试水，别冒险
Mid证据链成型、交锋期 —— CRACK → GOTCHA 决定节奏；中压/重压开始交换
Late盲注高压 —— 不动手就被磨死；Effective Stack 决胜，ALL IN 一决生死
打牌 → READ 碎片 → 证据链 → CRACK → GOTCHA（对 = EXECUTION / 错 = COUNTER）→ 真实筹码结算 → 下一手
