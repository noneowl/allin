♠ ALLIN · 新手引导 1 / 6

① READ：每手限量，一次读一组

  • READ 按钮显示 2/2 —— 每手只有 2 次，用完变 0/2 灰掉， 下一手重新填满；按钮外圈是冷却转圈（冷却极短）
  • 一次 READ 返回一组 3–5 条碎片：Boss 头旁成组闪现、逐行错开， 0.5–1.5 秒后淡出（他越冷静闪得越久），同时全部进入右侧 READ Fragments 面板
  • 碎片混着真心话、无关杂念、他自己的错觉，绝不标类型 —— 只能拿牌面、注码、行动交叉验证
  • 只有你的回合才能 READ —— 次数宝贵，想好再读

② PIN：把一条情报钉进 Known

  • 带 📌 的碎片行（本手工 READ 出的）可以 PIN —— 点一下就钉进 READ Fragments 顶部的 Known 卡片
  • 单槽位：新 PIN 覆盖旧 PIN，一手只能记住一条
  • 被验证后 Known 卡打 ✓，被 PIN 的行高亮 —— 这条情报已经被你在牌桌上兑现过
  • GOTCHA 阶段 Boss 主动泄漏的碎片没有 id、不能 PIN —— 只能看，来不及钉

③ 新 CRACK = 情报 × 行动

  • 不再是碎片拼语义 —— CRACK 的公式是： PIN 住的真话 × 你做出的正确行动 × Boss 当时的真实意图
  • 例：他「怕你继续加注」（fear_raise）被你 PIN 住 → 你真的加注了 → 屏幕白闪震屏，大字副标 fear_raise × RAISE
  • NOISE / DISTORTION 天然没有标签 —— PIN 错了永远验证不出来， 只会白占你的槽位
  • Boss 再次进攻后意图会变，旧情报自然作废；同一 PIN 验证过一次就不再重复生效
  • 本手攒够 N 个 CRACK（默认 2）→ GOTCHA 解锁点亮

④ GOTCHA：押上一切的负债决胜

  • 点 GOTCHA!（无任何二选一）→ 全屏宣告、屏幕进入 红金警戒态，双方解除筹码上限
  • 可以负债：投入不再受剩余筹码限制，筹码堆会回缩到 0、 数字变红（如 -200）—— 欠的债就是你的新生命值
  • 行动只剩 FOLD | CALL/CHECK | RAISE： 没有任何数字输入，金额全部由服务端按阶梯给出
  • 任意一方 CALL / RAISE 都会触发 心理泄漏： 更快更密的金色碎片（4–6 条、带 depth 角标），越深越真
  • READ 在 GOTCHA 中禁用（显示 READ —）—— 情报只从泄漏里来

⑤ 阶梯：每一次加注，风险翻倍

RAISE 至 N金额 = 当前注 + 阶梯（按钮上直接写着「至 N」，回车即出）
阶梯起点进入 GOTCHA 时 = 本街上次加注尺寸（至少一个大盲）
阶梯翻倍任意一方完成一次完整加注 → 阶梯 ×2：100 → 200 → 400 → 800 …
  • 每多僵持一轮，底下的债就翻一倍 —— 要么快刀 CALL 结束对轰，要么继续加注压死他
  • Effective Stack 在这里只是参考：NORMAL 的安全上限已经解除

⑥ 统一结算：欠债也一起算

  • GOTCHA 只有 FOLD 或摊牌才会结束，随后统一结算： 退还未跟部分 → Pot 归拢全部投入（含负债投入）→ 赢家连本带债一起收
  • 债务被 Pot 覆盖：赢了就一笔勾销，输了就是终局 —— 结算后筹码 ≤ 0 立即判负，绝不允许负数筹码进入下一手
  • 盲注照旧按手数阶梯升级，不动手也会被磨死； 把 Boss 的筹码打到 0 = VICTORY，你的归零 = DEFEAT
Boss 行动 → READ（2 次/手 · 一次一组）→ PIN 真话 → 正确行动 → CRACK ×2 → GOTCHA 负债决胜（阶梯翻倍 · 心理泄漏）→ 统一结算 → 下一手
