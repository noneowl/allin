♠ ALLIN · 新手引导 1 / 6

① 基础循环：心理窗口就是他的破绽

Boss 行动 → 🧠 Tell Window 开启 → READ（耗 Focus）/ 直接回应 → PIN × 正确行动 = CRACK → Boss 心理状态推进 → 状态改写下一轮下注权重与 Tell 质量 → 他 EXPOSED + 转/河高承诺 = GOTCHA 窗口
  • READ 不再是随时能点的按钮 —— 只在他刚做完行动、还等你回应的那一瞬开放； 你自己的任何成功行动都会让窗口即刻关闭
  • CRACK 判定发生在你回应落地的那一刻：命中 → 白闪大字 + CALM → SHAKEN → EXPOSED 状态横幅（双方对称，同样会被打崩）
  • 心理与筹码彻底分离：赢底池、输底池都不动情绪 —— 只有「被看穿」（CRACK / 被拖进 GOTCHA）才会推进状态
  • 状态跨手持续：你把他打到 EXPOSED，他就带着破绽打到下一手里

② Tell Window 与 Focus：一窗一批

  • READ 与 GOTCHA 共用底部行动栏的同一个特殊位：窗口开启时 READ 呼吸高亮、桌面中央浮出「OPENING! 心理波动：微弱/明显/强烈」—— 点 READ，中央弹出 3–5 行大字选择层，点一条即钉住（其余即刻消失、层随即关闭， 其他行动按钮临时禁用）；窗口一灭该位置立刻灰掉
  • Focus 取代每手 2 次：翻前 0（不开放 READ）； 每进 flop / turn / river 各 +1，上限 2， 没用完可以带到下一条街；每手牌从 0 重新开始
  • 按钮显示 FOCUS 1/2：每按一次 READ 消耗 1 点， 耗尽即禁用；读完仍有极短的冷却转圈
  • 一窗一批：一批碎片只属于当前这个窗口 —— 你一做出回应（无论 CRACK 成没成），服务端无条件清空碎片与 PIN， 旧窗口的 📌 不能再钉到新窗口上

③ 碎片质量：他刚做什么 × 第几条街 × 他什么状态

  • 真话浓度是公式化的：他刚做的行动越重（check < bet < call < raise < heavy < allin）、 街段越靠后（flop < turn < river）、 他心理越崩（CALM < SHAKEN < EXPOSED），真话占比越高
  • 翻前与 CALM 的 check 窗口 = 最难读的一手；河牌 + EXPOSED 的重注窗口 = 一眼看穿
  • 三类信息永远混在一起、绝不标类型：真心话、无关杂念、他自己的错觉
  • 交叉验证三件套：行动史（他刚 X）＋ 牌面与街段（公共牌支持吗）＋ 心理状态与 stateHint（他现在漏真话还是在演）

④ PIN × 行动 = CRACK：三态推进

  • 三要件缺一不可：PIN 住的真话 × 你做出的匹配行动 × 他当时的真实意图； 点选碎片的瞬间会生成 HYPOTHESIS（他希望你 FOLD / 他害怕 RAISE）， 行动按钮下方的关系小字（顺从/挑战/施压…）只是这句话的翻译 —— 你一行动，假设与提示立即清空；CRACK 判定仍发生在回应落地那一刻
  • 每次 CRACK 都会紧接一条状态推进横幅： 冷静😏 → 动摇😳 → 暴露😵；NOISE / DISTORTION 没有标签，钉错了永远验不出来
  • 他的状态直接改写下一轮：SHAKEN Tell 变多、更凶更爱演； EXPOSED Tell 最浓、打法明显失控，并获得 GOTCHA 资格
  • 你被他 CRACK 也一样掉状态格（HUD「你」旁的脸会变）—— 心理是双向的

⑤ Boss 反读：PLAYER CRACKED

  • Boss 也在数你的习惯。三个明显模式： 别连续被重注打跑（面对重注 fold 次数攒够 → 他推重注等你跑）； 别什么都接（跟注次数攒够 → 他加注等你接）； 输急眼别乱开火（当激进方输牌攒够 → 他让牌等你开火）
  • 模式成立 + 他当次行动布下陷阱 → 你的回应一踩中，红色 PLAYER CRACKED 大字砸脸 + 停顿，Battle Log 记下 「他在利用你：{为什么}」—— 他也在看你
  • 同时你的心理状态格被推进一档（冷静 → 动摇 → 暴露）， Boss 的台词与下注会更放肆
  • 破解：换窗口换打法 —— 你不按老路走，陷阱就作废，他会重新评估
  • 看穿他的预测再应对有三种结果：EVASION（照他的预测退， 但你已看穿 —— 稳住不掉状态）、BREAK（不按预测走 —— 打乱了他的剧本）、 REVERSAL（不按预测走还反压 —— 抢回主动，反攻窗口随之而来）

⑥ GOTCHA：资格 × 时机的负债决胜

  • 点亮条件缺一不可：他是 EXPOSED（资格）＋ 转牌/河牌（高承诺街段）＋ 他刚做过 bet / raise / allin（同一条街）＋ 轮到你的回合 —— 按钮亮了才能按
  • 点 GOTCHA! → 全屏宣告、屏幕进入红金警戒态， 双方解除筹码上限，可以负债（筹码堆回缩到 0、数字变红如 -200）
  • 行动只剩 FOLD | CALL/CHECK | RAISE：金额全由服务端按阶梯给出， 每完成一次完整加注 阶梯 ×2：100 → 200 → 400 … 要么快刀 CALL 结束对轰，要么继续加注压死他
  • 任意一方 CALL / RAISE 触发心理泄漏： 更快更密的金色碎片（4–6 条、带 depth 角标），越深越真；READ 在负债阶段禁用
  • 统一结算：退未跟部分 → Pot 归拢含负债投入 → 赢家连本带债一起收； 结算后筹码 ≤ 0 立即判负，绝不允许负数进入下一手； 盲注照旧按手数阶梯升级，Boss 归零 = VICTORY
Boss 行动 → 心理窗口 READ/回应 → CRACK 推进三态 → 反读盯住你的习惯 → EXPOSED 高承诺 = GOTCHA 负债决胜（阶梯翻倍 · 心理泄漏）→ 统一结算 → 下一手
