♠ ALLIN · 新手引导 1 / 5

把他的筹码打到 0，就是击败他

  • 双方各 1000 筹码：筹码 = 下注资源 = 生命值 = 战斗进度
  • 他的筹码归零 → BREAK，战斗胜利；你的归零 → 战斗失败
  • 没有技能栏 —— 所有攻防都通过扑克动作完成，牌桌本身就是整场战斗
读他 → 影响他 → 让他失控 → 他在牌桌上犯错 → 你赢走筹码

扑克动作 = 战斗动作

下注 / 加注攻击、施压 —— 让他做决定
跟注防御、接招 —— 抓住他的诈唬就是一次反击
过牌示弱、诱敌 —— 等他露出破绽再动手
弃牌撤退、止损 —— 输小的不算输
全下必杀 —— 高风险决战，筹码即生命

他也在用同样的动作打你。拿到好牌只是一半，看穿他出什么牌才是另一半。

三个心理操作（每手限次）

  • READ ×2：一条模糊的心理提示 —— 是情绪和倾向，不是答案。 「他似乎非常期待你弃牌」→ 自己判断他是在演还是真的有货
  • 挑衅 ×1：让他更凶、注更大、更爱演 —— 然后准备好大注抓他
  • 质疑 ×1：攻击他的言行矛盾，命中直接动摇他的心理
  • 施压 ×1：让他更想退缩 —— 掩护你自己的诈唬

言语不会直接偷走他的筹码：它先改变他的心态，再通过他的下注把错误付给你。

异议窗口：看见破绽就按

  • 他说的话和下的注对不上（放狠话却下小注）、或打法 前后矛盾（一路示弱突然超池全推）时，台词播放期间会出现红色 「异议！」按钮
  • 倒计时内点击 → 打击演出 + 他的心理状态恶化一档
  • 窗口只在真矛盾时出现 —— 假窗口根本不存在，看到就按
  • 错过了也别急：本手内还可以用 质疑 追打这条矛盾

他在崩坏，就是你在赢

  • 心理状态单向恶化：冷静 😏 → 动摇 😳 → 上头 😡 → 崩坏 🤯
  • 越被动越明显：台词变嘴硬、诈唬变多、注码变大、弃牌阈值下降 —— 头像表情、配色、状态标签都会告诉你
  • 崩坏后他甚至会自相矛盾地失控，READ 也变得清晰 —— 越到后面越好读
